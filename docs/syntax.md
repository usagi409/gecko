コード内のスペースは全角スペースでも可能。文字列は " か ' で囲む。コメントは # から行末まで。ファイルは UTF-8 で保存する。

## 代入
Pythonの`=`に相当。変数に値を入れる。
使い方:
名前 は "うさぎ"
点数 は 85
コピー は 変数 名前
pythonでの動き:
名前 = "うさぎ"
点数 = 85
コピー = 名前
注意: 右側の裸の言葉は変数名として扱われる。変数を参照したいときは`変数 名前`の形でも書ける。

## もし / elif / else
Pythonの`if` / `elif` / `else`に相当。条件で分岐する。
使い方:
もし 点数 が 80 以上 なら
    表示する("合格")
ではなくて 点数 が 60 以上 なら
    表示する("再試験")
でなければ
    表示する("不合格")
pythonでの動き:
if 点数 >= 80:
    print("合格")
elif 点数 >= 60:
    print("再試験")
else:
    print("不合格")
注意: 条件の終わりは`なら`。ブロックの中はインデントで表す。`ではなくて`は`それ以外もし`など、`でなければ`は`それ以外` / `違えば`も同義。

---

比較
条件の中で使う比べ方。
使い方:
A が B なら                  等しい
A が B ではない なら          等しくない（`じゃない` / `等しくない` も同義）
A が B 以上 / 以下 なら       以上 / 以下（その数を含む）
A が B より大きい / 小さい なら  未満 / 超（その数を含まない）
pythonでの動き:
A == B
A != B
A >= B / A <= B
A > B / A < B

論理
条件の組み合わせ。
使い方:
もし 点数 が 80 以上 かつ 100 以下 なら
    表示する("範囲内")
もし 名前 が "うさぎ" または 名前 が "かめ" なら
    表示する("動物")
もし でない 点数 が 0 なら
    表示する("ゼロではない")
pythonでの動き:
if 点数 >= 80 and 点数 <= 100:
if 名前 == "うさぎ" or 名前 == "かめ":
if not 点数 == 0:
注意: `かつ`の後は主語を省略できる（直前の主語が引き継がれる）。

繰り返し（for）
Pythonの`for`に相当。書き方は4通り。
使い方:
繰り返し 商品 を 買い物:
繰り返し i を 範囲(3):
繰り返し i を 1 から 3 まで:
繰り返し 商品 を 買い物 の 0 から 1 まで:
pythonでの動き:
for 商品 in 買い物:
for i in range(3):
for i in range(1, 3 + 1):
for 商品 in 買い物[0:1 + 1]:
注意: `まで`は常に b を含む。`範囲`の始まり番号はカウント設定依存（functions.md の`範囲`を参照）。

繰り返し（while）
Pythonの`while`に相当。条件が成り立つ間くり返す。
使い方:
残り は 3
ながら 残り が 0 より大きい なら
    表示する(残り)
    残り は 残り - 1
pythonでの動き:
残り = 3
while 残り > 0:
    print(残り)
    残り = 残り - 1

無限ループ / 抜ける / 続ける
Pythonの`while True` / `break` / `continue`に相当。
使い方:
n は 0
ループ:
    n は n + 1
    もし n が 2 なら
        続ける
    もし n が 5 なら
        抜ける
    表示する(n)
pythonでの動き:
n = 0
while True:
    n = n + 1
    if n == 2:
        continue
    if n == 5:
        break
    print(n)
注意: `抜ける`のない`ループ`は永遠に終わらない。

関数定義
Pythonの`def` / `return`に相当。
使い方:
関数 挨拶(名前):
    戻り値 "こんにちは、" + 名前
表示する(挨拶("うさぎ"))
pythonでの動き:
def 挨拶(名前):
    return "こんにちは、" + 名前
print(挨拶("うさぎ"))

クラス
Pythonの`class`に相当。メソッドは self を受け取る。
使い方:
クラス 動物:
    関数 鳴く(self):
        戻り値 "..."
犬 は 動物()
表示する(犬.鳴く())
pythonでの動き:
class 動物:
    def 鳴く(self):
        return "..."
犬 = 動物()
print(犬.鳴く())

エラー処理
Pythonの`try` / `except` / `finally`に相当。
使い方:
試す:
    数 は 整数(入力("数字？"))
捕まえる 値エラー as e:
    表示する("数字じゃない")
最終:
    表示する("終わり")
pythonでの動き:
try:
    数 = int(input("数字？"))
except ValueError as e:
    print("数字じゃない")
finally:
    print("終わり")
注意: 例外の日本語別名は`値エラー` / `型エラー` / `零除算エラー` / `ファイルエラー` / `インデックスエラー` / `キーエラー`。

ファイル操作（with）
Pythonの`with`に相当。終わったら自動でファイルを閉じる。
使い方:
一緒に 開く("memo.txt") as f:
    中身 は f.read()
pythonでの動き:
with open("memo.txt") as f:
    中身 = f.read()
注意: `read()`などのメソッド名は Python のまま（英語）。

import
Pythonの`import`に相当。
使い方:
読み込む math
読み込む math として m
pythonでの動き:
import math
import math as m
注意:現状、importしたモジュールは日本語コードに対応していないため正しいpython文法で書く必要がある。

定数
Pythonの`True` / `False` / `None`に相当。
使い方:
フラグ は 真
結果 は なし
pythonでの動き:
フラグ = True
結果 = None
