# 構文リファレンス

gecko の「構文」（カッコで呼ばないもの）をまとめた文書。
カッコで呼ぶ組み込み関数は [functions.md](functions.md)、`設定.待機` / `設定.カウント` は [settings.md](settings.md) を参照。

コード内のスペースは全角スペースでも可能。文字列は `"` か `'` で囲む。コメントは `#` から行末まで。ファイルは UTF-8 で保存する。

v0.2.0 で `ながら` と前置きの `でない`（`もし でない x が 1 なら`）は廃止されました。

---

## 代入

Pythonの `=` に相当。変数に値を入れる。

使い方:
    名前 は "うさぎ"
    点数 は 85
    コピー は 変数 名前

pythonでの動き:
    名前 = "うさぎ"
    点数 = 85
    コピー = 名前

注意: 右側の裸の言葉は変数名として扱われる。変数を参照したいときは `変数 名前` の形でも書ける。

## もし / ではなくて / でなければ

Pythonの `if` / `elif` / `else` に相当。条件で分岐する。

使い方:
    もし 点数 が 80 以上 なら
        表示する("合格")
    ではなくて 点数 が 60 以上 なら
        表示する("再試験")
    でなければ
        表示する("不合格")

pythonでの動き:
    if 点数 >= 80:
        print("合格")
    elif 点数 >= 60:
        print("再試験")
    else:
        print("不合格")

注意: 条件の終わりは `なら`。ブロックの中はインデントで表す。`ではなくて` は `それ以外もし` など、`でなければ` は `それ以外` / `違えば` も同義。

---

## 比較

条件の中で使う比べ方。

使い方:
    | gecko | 意味 |
    | --- | --- |
    | A が B なら | 等しい |
    | A が B に なる なら | 等しい（同義） |
    | A が B ではない なら | 等しくない（`じゃない` / `等しくない` も同義） |
    | A が B 以上 なら / A が B 以下 なら | 以上 / 以下（その数を含む） |
    | A が B より大きい なら | 超（その数を含まない） |
    | A が B より小さい なら | 未満（その数を含まない） |

pythonでの動き:
    A == B
    A != B
    A >= B / A <= B
    A > B / A < B

---

## 論理

条件の組み合わせ。

使い方:
    もし 点数 が 80 以上 かつ 100 以下 なら
        表示する("範囲内")
    もし 名前 が "うさぎ" または 名前 が "かめ" なら
        表示する("動物")
    もし x が 1 でない なら
        表示する("1 ではない")

pythonでの動き:
    if 点数 >= 80 and 点数 <= 100:
        ...
    if 名前 == "うさぎ" or 名前 == "かめ":
        ...
    if not (x == 1):
        ...

注意: `かつ` の後は主語を省略できる（直前の主語が引き継がれる）。`でない` は**直前の条件のかたまり**を否定する。2 つの値の「等しくない」は `ではない` / `じゃない` を使う。前置きの `でない` は廃止。

## 繰り返し（for）

Pythonの `for` に相当。

使い方:
    繰り返し 商品 を 買い物:
    繰り返し i を 範囲(3):
    繰り返し i を 1 から 3 まで:
    繰り返し 商品 を 買い物 の 0 から 1 まで:
    買い物 の 商品 ごとに 繰り返す:
    買い物 から 商品 を 取り出して 繰り返す:
    3 回 繰り返す:

pythonでの動き:
    for 商品 in 買い物:
    for i in range(3):
    for i in range(1, 3 + 1):
    for 商品 in 買い物[0:1 + 1]:
    for 商品 in 買い物:
    for 商品 in 買い物:
    for _ in 範囲(3):

注意: `まで` は常に b を含む。`範囲` の始まり番号はカウント設定依存（functions.md の `範囲` を参照）。`N 回 繰り返す` にカウンタ変数は無い。番号が要るなら `繰り返し i を 範囲(N):` を使う。

## 繰り返し（while 系）

Pythonの `while` に相当。

### 条件が真の間くり返す

使い方:
    残り が 0 より大きい なら 繰り返す:
    残り が 0 より大きい あいだ:
    残り が 0 より大きい あいだ ずっと:
        表示する(残り)
        残り は 残り - 1

pythonでの動き:
    while 残り > 0:
        print(残り)
        残り = 残り - 1

### 条件が真になるまでくり返す（Scratch の repeat until）

使い方:
    残り が 0 に なる まで 繰り返す:
        残り は 残り - 1

pythonでの動き:
    while not (残り == 0):
        残り = 残り - 1

注意: `ながら` は v0.2.0 で廃止。上の語尾形式を使う。

## 無限ループ / 抜ける / 続ける

Pythonの `while True` / `break` / `continue` に相当。

使い方:
    n は 0
    ずっと:
        n は n + 1
        もし n が 2 なら
            飛ばす
        もし n が 5 なら
            やめる
        表示する(n)

pythonでの動き:
    n = 0
    while True:
        n = n + 1
        if n == 2:
            continue
        if n == 5:
            break
        print(n)

注意: `ずっと` は `ループ` と同義。`やめる` は `抜ける` の、`飛ばす` は `続ける` の別名（`飛ばす` = その回だけ飛ばす）。`抜ける` のない無限ループは永遠に終わらない。

## 関数定義

Pythonの `def` / `return` に相当。

使い方:
    定義 挨拶(名前):
        戻り値 "こんにちは、" + 名前
    表示する(挨拶("うさぎ"))

pythonでの動き:
    def 挨拶(名前):
        return "こんにちは、" + 名前
    print(挨拶("うさぎ"))

注意: `関数` と `定義` は同義。

## クラス

Pythonの `class` に相当。メソッドは self を受け取る。

使い方:
    クラス 動物:
        関数 鳴く(self):
            戻り値 "..."
    犬 は 動物()
    表示する(犬.鳴く())

pythonでの動き:
    class 動物:
        def 鳴く(self):
            return "..."
    犬 = 動物()
    print(犬.鳴く())

## エラー処理

Pythonの `try` / `except` / `finally` に相当。

使い方:
    試す:
        数 は 整数(入力("数字？"))
    捕まえる 値エラー なら:
        表示する("数字じゃない")
    最後に:
        表示する("終わり")

pythonでの動き:
    try:
        数 = int(input("数字？"))
    except ValueError as エラー:
        print("数字じゃない")
    finally:
        print("終わり")

注意: `捕まえる E なら:` を使うとエラー本体は変数 `エラー` に自動で入る。古い形 `捕まえる 値エラー as e:` も使える。`最終` と `最後に` は同義。例外の日本語別名は `値エラー` / `型エラー` / `零除算エラー` / `ファイルエラー` / `インデックスエラー` / `キーエラー`。

## ファイル操作（with）

Pythonの `with` に相当。終わったら自動でファイルを閉じる。

使い方:
    一緒に 開く("memo.txt") を f として:
        中身 は f.read()

pythonでの動き:
    with open("memo.txt") as f:
        中身 = f.read()

注意: 古い形 `一緒に 開く("memo.txt") as f:` も使える。`read()` などのメソッド名は Python のまま（英語）。

## import

Pythonの `import` に相当。

使い方:
    読み込む math
    読み込む math として m
    math を m として 読み込む

pythonでの動き:
    import math
    import math as m
    import math as m

注意: 現状、importしたモジュールは日本語コードに対応していないため、正しいPython文法で書く必要がある。
