# 組み込み関数リファレンス

モード = `設定.カウント` の設定（書かなければ 0）。

---

## 表示する / 表示
Python 相当: `print`
概要: 文字や数をコンソールに出す。
使い方:
    表示する("こんにちは")
    表示する("点数: " + 文字列(点数))

## 入力 / 入力する
Python 相当: `input`
概要: キーボード入力を**文字列**として受け取る。
使い方:
    名前 は 入力("名前は？ ")
注意: 数字が欲しいなら囲む。
    点数 は 整数(入力("点数は？ "))

## 整数 / 実数 / 文字列
Python 相当: `int` / `float` / `str`
概要: 型の変換。
使い方:
    整数("85")     → 85
    文字列(85)     → "85"

## 長さ
Python 相当: `len`
概要: リストの要素数 / 文字の長さ。
使い方:
    長さ(買い物)

## 開く
Python 相当: `open`
概要: ファイルを開く。`一緒に ... as ...` とセットで。
使い方:
    一緒に 開く("memo.txt") as f:
        中身 は f.read()
注意: `read()` などのメソッド名は Python のまま（英語）。

## 範囲
Python 相当: `range`（モードで挙動変化）
概要: 繰り返し用の番号の列。
使い方:
    繰り返し i を 範囲(3):
    繰り返し i を 範囲(1, 4):
モードによる変化:
    範囲(3)   → モード0: 0,1,2 / モード1・全部: 1,2,3
    範囲(a,b) → モード0: a〜b-1 / モード1・全部: a〜b

## 列挙
Python 相当: `enumerate`（開始番号がモード依存）
概要: 番号と中身をセットで回す。
使い方:
    繰り返し i と 商品 を 列挙(買い物):
モードによる変化: 番号がモード0=0始まり / 1・全部=1始まり

## 追加
Python 相当: `list.append`
概要: リストの末尾に 1 つ足す。
使い方:
    追加(買い物, "ばなな")

## 挿入
Python 相当: `list.insert`
概要: 指定位置に入れる。
使い方:
    挿入(買い物, 0, "めろん")
モードによる変化: 位置がモード0=0始まり / 1・全部=1始まり

## 消す
Python 相当: `list.remove`
概要: 最初に見つかった一致を削除。無いとエラー。
使い方:
    消す(買い物, "みかん")

## 取り出す
Python 相当: `list.pop`
概要: 指定位置の要素を取り出して削除（省略時は末尾）。
使い方:
    取り出す(買い物)
    取り出す(買い物, 0)
モードによる変化: 位置がモード0=0始まり / 1・全部=1始まり

## 並び替え / 逆順
Python 相当: `list.sort` / `list.reverse`
概要: その場で並び替え / 反転。戻り値は無い。
使い方:
    並び替え(買い物)
    逆順(買い物)

## 何番目
Python 相当: `list.index`
概要: 最初に見つかった位置を返す。
使い方:
    何番目(買い物, "みかん")
モードによる変化: 戻り値がモード0=0始まり / 1・全部=1始まり

## 部分
Python 相当: スライス（`list[a:b+1]` 相当）
概要: a〜b 番目（**b を含む**）を新しいリストで取り出す。
使い方:
    部分(買い物, 0, 1)
モードによる変化:
    モード0: 0始まり・b含む
    モード1・全部: 1始まり・b含む

## 拡張
Python 相当: `list.extend`
概要: 別のリストからまとめて末尾に足す。
使い方:
    拡張(買い物, ["もも", "かき"])

## 結合
Python 相当: `str.join`（**引数の順が逆**）
概要: 文字列のリストを区切り文字で 1 つにする。
使い方:
    結合(買い物, ",")
注意: Python では `",".join(list)`。gecko はリストが先。

## 最大 / 最小 / 合計
Python 相当: `max` / `min` / `sum`
概要: 数値リストの最大 / 最小 / 合計。
使い方:
    最大(点数リスト)
