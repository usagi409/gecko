# 組み込み関数リファレンス

カウント設定とは、`設定.カウント` の設定のこと。コードの初めに置く。書かれていなかった場合0からスタートになる。以下の pythonでの動き はモード 0（デフォルト）の挙動。違いは各関数の『モードによる変化』を参照。
使い方:
設定.カウント(0)
設定.カウント(1,　全部)
設定.カウント(1)

---

## 表示する / 表示
Pythonの`print`に相当。文字や数をコンソールに出します。
使い方:
    表示する("hello world")
    表示する("点数: " + 文字列(点数))
pythonでの動き:
    print("hello world")
    print("点数: " + str(点数))

## 入力 / 入力する
Pythonの`input`に相当。キーボード入力を**文字列**として受け取り、変数に返す。
使い方:
    名前 は 入力("名前は？ ")
注意: 数字が欲しいなら囲む。
    点数 は 整数(入力("点数は？ "))
pythonでの動き:
    名前 = input("名前は？")
数字の場合
    名前 = int(input("点数は？ "))

## 整数 / 実数 / 文字列
Pythonの`int` / `float` / `str`に相当。値の型を変換する。
使い方:
    整数("85")     → 85
    文字列(85)     → "85"
pythonでの動き:
    int("85")     → 85
    str(85)     → "85"

## 長さ
Pythonの`len`に相当。リストの要素数 / 文字の長さなどを調べる。
使い方:
    長さ(買い物)
pythonでの動き:
    len(買い物)

## 開く
Pythonの`open`に相当。ファイルを開く。`一緒に ... as ...` とセットで使う。
使い方:
    一緒に 開く("memo.txt") as f
        中身 は f.read()
pythonでの動き:
    with open("memo.txt") as f:
        中身 = f.read()
`read()` などのメソッド名は Python のまま（英語）なので注意。

## 範囲
Pythonでの`range`に相当（カウントの設定により挙動変化）。番号を順番に出力する。
使い方:
    繰り返し i を 範囲(3)
    繰り返し i を 範囲(1, 4)
pythonでの動き:
    for i in range(3):
    for i in range(1,4):
モードによる変化:
    範囲(3)   → モード0の場合: 0,1,2 / モード1の場合(一部,全部問わず): 1,2,3
    範囲(a,b) → モード0の場合: a〜b-1 / モード1の場合(一部,全部問わず): a〜b

## 列挙
Pythonの`enumerate`に相当。（開始番号がモード依存）リストの番号と中身をセットで返す。
使い方:
    繰り返し i と 商品 を 列挙(買い物)
pythonでの動き:
    for i, 商品 in enumerate(買い物)
モードによる変化: リスト番号はカウント設定が0からであれば0から、1からであれば1から始まる。

## 追加
Pythonの`list.append`に相当。指定したリストの末尾に 1 つ要素を足す。
使い方:
    追加(買い物, "ばなな")
pythonでの動き:
    買い物.append("ばなな")

## 挿入
Pythonの`list.insert`に相当。指定したリストの指定位置に要素を入れる。
使い方:
    挿入(買い物, 0, "めろん")
pythonでの動き:
    買い物.insert(0, "めろん")
モードによる変化: リスト番号はカウント設定が0からであれば0から、1からであれば1から始まる。

## 消す
Pythonの`list.remove`に相当。同じ値の入っている一番リスト番号が若い要素を削除する。リストにない値を入力するとエラー。
使い方:
    消す(買い物, "みかん")
pythonでの動き:
    買い物.remove("みかん")

## 取り出す
Pythonでの`list.pop`に相当。指定位置の要素を取り出して削除する（指定位置を省略した場合は末尾）。
使い方:
    取り出す(買い物)
    取り出す(買い物, 0)
pythonでの動き:
    買い物.pop()
    買い物.pop(0)
モードによる変化:リスト番号はカウント設定が0からであれば0から、1からであれば1から始まる。

## 並び替え / 逆順
Pythonの`list.sort` / `list.reverse`に相当。
概要: その場で並び替え / 反転。戻り値は無い。
使い方:
    並び替え(買い物)
    逆順(買い物)

## 何番目
Pythonの`list.index`に相当。指定した値と合致する一番リスト番号が若い要素を返す。その要素の位置を返す。
使い方:
    何番目(買い物, "みかん")
pythonでの動き:
    買い物.index("みかん")
モードによる変化: 戻り値はカウント設定が0からであれば0から、1からであれば1から始まる。

## 部分
Pythonのスライス（`list[a:b+1]`）に相当。指定したリストのa〜b 番目（**b を含む**）を新しいリストで取り出す。
使い方:
    部分(買い物, 0, 1)
pythonでの動き:
    買い物[a:b+1]
モードによる変化:
    カウント設定が0から: リスト番号が0始まり・b含む
    カウント設定が1から: リスト番号が1始まり・b含む

## 拡張
Pythonでの`list.extend`に相当。指定のリストに要素をまとめて末尾に足す。
使い方:
    拡張(買い物, ["もも", "かき"])
pythonでの動き:
    買い物.extend(["もも", "かき"])

## 結合
Pythonでの`str.join`（**引数の順が逆**）に相当。文字列**のみ**のリストの要素を指定の区切り文字で区切り 1 つの文字列にする。
使い方:
    買い物メモ　は　結合(買い物, ",")
pythonでの動き:
    買い物メモ = ",".join(買い物)
注意: Python では `",".join(list)`。gecko はリストが先。

## 最大 / 最小 / 合計
Pythonでの`max` / `min` / `sum`に相当。数値リストの最大 / 最小 / 合計。
使い方:
    最高点　は　最大(点数リスト)
pythonでの動き:
    最高点 = max(点数リスト)
