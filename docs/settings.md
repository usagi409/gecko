# 設定

    設定.待機(止める)        終わりで窓を残す（デフォルト）
    設定.待機(止めない)      終わりで窓を閉じる
    設定.カウント(0)         全部 0 始まり（デフォルト）
    設定.カウント(1)         順番系だけ 1 始まり
    設定.カウント(1, 全部)   全部 1 始まり

## 設定は先頭以外に書くとエラーになります
`設定.*` はファイルの先頭（コードより前）にだけ書けます。
コメントと空行は挟んでよいです。

    設定.カウント(1から)     ← OK
    表示する("こんにちは")
    設定.待機(止めない)      ← エラー！

## 設定を書かなかった場合
- カウント: 全部 0 始まり
- 待機: あり（窓が残る）

## 一部 1 始まり（設定.カウント(1)）のとき 1 始まりに変わるもの
- `範囲` の番号
- `列挙` の番号
- `何番目` の戻り値
- `挿入` / `取り出す` の位置
- `部分` と `リスト の a から b まで` の範囲

変わらないもの（0 始まりのまま）:
- `リスト[i]` / `リスト[a:b]` の生のカッコ
  （これらが 1 始まりになるのは `設定.カウント(1, 全部)` のときだけ）
