# gecko

日本語で書けるプログラミング言語。

    名前 は "うさぎ"
    もし 名前 が "うさぎ" なら
        表示する("うさぎです")

## インストール
Releases から `gecko-setup-*.exe` をダウンロードして実行。
Python は不要です。.gek のダブルクリック実行も自動登録されます。

## はじめかた
1. `sample.gek` をダブルクリック
2. メモ帳で開いて（UTF-8）、中身を書き換える
3. もう一度ダブルクリック
