# gecko

日本語で書けるプログラミング言語。コードは `.gek` ファイルに書きます。

    点数 は 85
    もし 点数 が 80 以上 かつ 100 以下 なら
        表示する("合格！")

## インストール
Releases から `gecko-setup-*.exe` をダウンロードして実行するだけ。
- Python は不要
- `.gek` のダブルクリック実行を自動登録
- `gecko` コマンドを PATH に追加するかはチェックボックスで選択
-  설치先: `C:\Users\(ユーザー名)\AppData\Local\gecko`（画面で変更可）

## 使い方
- `.gek` をダブルクリック → 実行（終わりに窓が残ります）
- ターミナルから: `gecko program.gek`
  - 終わり方で止めたくない場合は 1 行目に `設定.待機(止めない)`

## 構文チートシート
| 日本語 | 意味 |
|---|---|
| `A は B` | 代入 |
| `もし ... なら` | if |
| `ではなくて ... なら` | elif |
| `でなければ` | else |
| `繰り返し x を リスト` | 各要素を回す |
| `繰り返し i を a から b まで` | 数値ループ（**b を含む**） |
| `ながら ... なら` | while |
| `ループ` | 無限ループ |
| `抜ける` / `続ける` | break / continue |
| `関数 f(x):` / `戻り値` | 関数 / return |
| `試す` / `捕まえる` / `最終` | try / except / finally |
