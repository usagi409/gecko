==============================================
  gecko ― 日本語プログラミング言語（ポータブル版）
==============================================

【概要】
gecko は、日本語でコードを書けるプログラミング言語です。
コードは .gek ファイルとして保存し、gecko コマンドで実行します。

    点数 は 85
    もし 点数 が 80 以上 なら
        表示する("合格")

このポータブル版は実行環境を同梱しているため、
Python のインストールなどは一切不要です。
解凍して、そのまま使えます。

【使い方】
(1) コマンドで実行する
    このフォルダを PATH に通している場合:
        gecko program.gek

    PATH に通していない場合（フルパス指定）:
        C:\(...解凍先...)\gecko.exe program.gek

    PATH の通し方:
      Windows の設定 →「環境変数」→ ユーザー変数の Path に
      このフォルダのパスを追加してください。

(2) ダブルクリック実行について
    ポータブル版は .gek の関連付けを登録しません。
    ダブルクリックで動かしたい場合は、同じリリースページにある
    インストーラ版 (gecko-setup-*.exe) をご利用ください。
    関連付け・PATH・アンインストール登録まで自動で行います。

【サンプルコードについて】
この zip にはサンプルコードは入っていません。
サンプルはインストーラ版、または以下にあります:
    - リポジトリ: https://github.com/（あなたのID）/gecko
    - Releases ページ: 上記リポジトリの Releases

【注意】
- 初回実行時に Windows の警告（SmartScreen）が出ることがあります。
  署名なしアプリのためで、信頼できる場合は
  「詳細情報」→「実行」で進んでください。
- .gek ファイルは UTF-8 で保存してください。
